# יומן התינוקת

אפליקציית ווב בעברית למעקב יומיומי אחרי הנקות, חיתולים, שינה ושאלות לרופאת הילדים. בנויה לטלפון: כל דיווח לוקח 2–4 לחיצות. בקבוק ושאיבה כבויים כברירת מחדל, ואפשר להפעיל אותם בהגדרות.

הנתונים נשמרים בטלפון, ואם מחברים גיליון Google Sheets הם נשמרים גם בגיליון שלכם. שני הטלפונים (שלך ושל אשתך) רואים אז את אותם נתונים. הגיליון משמש גם כגיבוי שאפשר לשחזר ממנו.

> היומן מציג רק את מה שנרשם. הוא לא מחליף ייעוץ רפואי.

## כתובת האפליקציה

**https://giladkam-hash.github.io/Baby/**

### הפעלה ראשונה (פעם אחת, דקה אחת)

1. ב-GitHub נכנסים למאגר ← **Settings** ← **Pages**.
2. ב-**Source** בוחרים **GitHub Actions**.
3. נכנסים ללשונית **Actions**, פותחים את הריצה האחרונה של "פרסום ל-GitHub Pages" ולוחצים **Re-run all jobs**. מכאן כל שינוי שנדחף למאגר מתפרסם לבד.
4. אחרי דקה-שתיים האפליקציה זמינה בכתובת שלמעלה.

### התקנה בטלפון

פותחים את הכתובת בטלפון ומוסיפים למסך הבית:
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ ← "הוספה למסך הבית" או "התקנת אפליקציה".

בפתיחה הראשונה כדאי להיכנס ל**הגדרות** ולמלא את שם התינוקת ותאריך הלידה.

מעכשיו פותחים את היומן מהאייקון, כמו אפליקציה רגילה.

## חיבור לגוגל שיטס (פעם אחת, כ-5 דקות, הכי נוח מהמחשב)

1. פותחים גיליון חדש: [sheets.new](https://sheets.new). אפשר לקרוא לו "יומן התינוקת".
2. בתפריט: **Extensions ← Apps Script**.
3. מוחקים את מה שכתוב שם ומדביקים את כל התוכן של [`apps-script/Code.gs`](apps-script/Code.gs). אפשר גם להעתיק אותו מתוך האפליקציה: הגדרות ← "העתקת הקוד".
4. שומרים (אייקון הדיסקט), ואז **Deploy ← New deployment**:
   - סוג: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים **Deploy** ומאשרים את ההרשאות. אם מופיע "Google hasn't verified this app": לוחצים Advanced ← Go to … (זה הסקריפט שלכם).
5. מעתיקים את ה-**Web app URL** (מתחיל ב-`https://script.google.com/macros/s/`) ומדביקים באפליקציה: הגדרות ← גיבוי וסנכרון ← חיבור.
6. בטלפון של אשתך: באותו מסך לוחצים "שליחת קישור חיבור", שולחים לה, והיא פותחת את הקישור. הטלפון שלה מתחבר לאותו גיליון.

### מה נשמר איפה

- **לשונית "יומן התינוקת" בגיליון:** כל רישום, עריכה או מחיקה נוספים כשורה חדשה, בעמודות קריאות (תאריך, שעה, סוג, צד, משך, הערה…). שום דבר לא נמחק משם.
- **תיקייה "יומן התינוקת – תמונות" בגוגל דרייב:** התמונות שצירפתם.
- **בטלפון:** עותק מלא, כך שהאפליקציה עובדת גם בלי אינטרנט. מה שנרשם בלי חיבור נשלח לגיליון כשהחיבור חוזר.

### שחזור

- **מחקתם רישום בטעות?** הגדרות ← "נמחקו לאחרונה" ← שחזור.
- **טלפון חדש או מחיקת נתונים בטלפון:** מחברים שוב לאותה כתובת (או פותחים קישור חיבור), והכול נטען מהגיליון. אפשר גם ללחוץ על "שחזור מלא מהגיליון".
- **קבצי גיבוי:** בהגדרות אפשר להוריד טבלת CSV (נפתחת באקסל ובשיטס) או גיבוי מלא כולל תמונות, ולייבא אותו בחזרה.

### חשוב

- לא למיין ולא למחוק שורות בלשונית "יומן התינוקת". לניתוחים יוצרים לשונית אחרת.
- כתובת הסקריפט היא המפתח לנתונים. משתפים אותה רק עם מי שצריך.
- מעדכנים את `Code.gs`? צריך לפרסם מחדש: Deploy ← Manage deployments ← עריכה ← Version: New version.
