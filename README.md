# יומן התינוקת

אפליקציית ווב בעברית למעקב יומיומי אחרי הנקות, חיתולים, שינה ושאלות לרופאת הילדים. בנויה לטלפון: כל דיווח לוקח 2–4 לחיצות. בקבוק ושאיבה כבויים כברירת מחדל, ואפשר להפעיל אותם בהגדרות.

הנתונים נשמרים בטלפון, ואם מחברים גיליון Google Sheets הם נשמרים גם בגיליון שלכם. שני הטלפונים (שלך ושל אשתך) רואים אז את אותם נתונים. הגיליון משמש גם כגיבוי שאפשר לשחזר ממנו.

> היומן מציג רק את מה שנרשם. הוא לא מחליף ייעוץ רפואי.

## כתובת האפליקציה

**https://giladkam-hash.github.io/Baby/**

### הפעלה ראשונה (פעם אחת, דקה אחת)

1. ב-GitHub נכנסים למאגר ← **Settings** ← **Pages**.
2. ב-**Source** בוחרים **GitHub Actions**.
3. נכנסים ללשונית **Actions**, פותחים את הריצה האחרונה של "פרסום ל-GitHub Pages" ולוחצים **Re-run all jobs**. מכאן כל שינוי שנדחף למאגר מתפרסם לבד.
4. אחרי דקה-שתיים האפליקציה זמינה בכתובת שלמעלה.

### התקנה בטלפון

פותחים את הכתובת בטלפון ומוסיפים למסך הבית:
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ ← "הוספה למסך הבית" או "התקנת אפליקציה".

בפתיחה הראשונה כדאי להיכנס ל**הגדרות** ולמלא את שם התינוקת ותאריך הלידה.

מעכשיו פותחים את היומן מהאייקון, כמו אפליקציה רגילה.

## חיבור לגוגל שיטס (פעם אחת, כ-5 דקות, הכי נוח מהמחשב)

1. פותחים גיליון חדש: [sheets.new](https://sheets.new). אפשר לקרוא לו "יומן התינוקת".
2. בתפריט: **Extensions ← Apps Script**.
3. מוחקים את מה שכתוב שם ומדביקים את כל התוכן של [`apps-script/Code.gs`](apps-script/Code.gs). אפשר גם להעתיק אותו מתוך האפליקציה: הגדרות ← "העתקת הקוד".
4. שומרים (אייקון הדיסקט), ואז **Deploy ← New deployment**:
   - סוג: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים **Deploy** ומאשרים את ההרשאות. אם מופיע "Google hasn't verified this app": לוחצים Advanced ← Go to … (זה הסקריפט שלכם).
5. מעתיקים את ה-**Web app URL** (מתחיל ב-`https://script.google.com/macros/s/`) ומדביקים באפליקציה: הגדרות ← גיבוי וסנכרון ← חיבור.
6. בטלפון השני: בטלפון המחובר נכנסים להגדרות ← גיבוי וסנכרון ← **"העתקת כתובת הגיליון"** ושולחים אותה. בטלפון השני פותחים את היומן **מהאייקון במסך הבית**, נכנסים להגדרות ← גיבוי וסנכרון, מדביקים בשדה ולוחצים **חיבור**. הרישומים שכבר יש בטלפון השני עולים לגיליון ומתאחדים עם הקיימים.
   - למה לא פשוט לפתוח את "קישור החיבור"? באייפון קישור נפתח ב-Safari, ולאפליקציה שבמסך הבית יש זיכרון נפרד. הרישומים שכבר נמצאים בה לא יעלו.

### מה נשמר איפה

- **לשונית "טבלה מסודרת" בגיליון:** הטבלה לקריאה. כל רישום מופיע בה פעם אחת, בגרסה האחרונה שלו, בלי רישומים שנמחקו, לפי סדר הזמן. היא נבנית מחדש בכל סנכרון, אז לא כותבים בה.
- **לשונית "יומן התינוקת" בגיליון:** כל רישום, עריכה או מחיקה נוספים כשורה חדשה, בעמודות קריאות (תאריך, שעה, סוג, צד, משך, הערה…). שום דבר לא נמחק משם.
- **תיקייה "יומן התינוקת – תמונות" בגוגל דרייב:** התמונות שצירפתם.
- **בטלפון:** עותק מלא, כך שהאפליקציה עובדת גם בלי אינטרנט. מה שנרשם בלי חיבור נשלח לגיליון כשהחיבור חוזר.

### שחזור

- **מחקתם רישום בטעות?** הגדרות ← "נמחקו לאחרונה" ← שחזור.
- **טלפון חדש או מחיקת נתונים בטלפון:** מחברים שוב לאותה כתובת (או פותחים קישור חיבור), והכול נטען מהגיליון. אפשר גם ללחוץ על "שחזור מלא מהגיליון".
- **קבצי גיבוי:** בהגדרות אפשר להוריד טבלת CSV (נפתחת באקסל ובשיטס) או גיבוי מלא כולל תמונות, ולייבא אותו בחזרה.

### חשוב

- לא למיין ולא למחוק שורות בלשונית "יומן התינוקת". לניתוחים יוצרים לשונית אחרת.
- כתובת הסקריפט היא המפתח לנתונים. משתפים אותה רק עם מי שצריך.
- מעדכנים את `Code.gs`? מדביקים את הקוד החדש, שומרים, ואז Deploy ← Manage deployments ← ✏️ עריכה ← Version: **New version** ← Deploy. הכתובת נשארת אותה כתובת, ואין צורך לחבר מחדש את הטלפונים.

## התראות לטלפון נעול (ntfy)

היומן עצמו לא יכול להתריע כשהוא סגור (מגבלה של אפל), לכן ההתראות יוצאות מהסקריפט שבגיליון דרך האפליקציה החינמית **ntfy**.

**איך זה עובד:** כל דיווח מסתנכרן לגיליון ← הסקריפט בודק כל דקה (`notifyTick`) ← שולח ל-ntfy ← ההתראה מופיעה בטלפון, גם נעול.

**הקמה (פעם אחת):** בהגדרות ← **התראות** ← "התראות גם כשהטלפון נעול" ← "איך מחברים". בקצרה:
1. מתקינים ntfy בכל טלפון, ונרשמים לשם הערוץ שהיומן יצר.
2. בגיליון: Apps Script ← מדביקים את `Code.gs` ← מריצים **setupNotifications** פעם אחת ← Deploy גרסה חדשה.
3. פותחים חשבון חינמי ב-ntfy.sh, יוצרים Access token ושומרים אותו ב-Apps Script ← Project Settings ← Script Properties (שם: `NTFY_TOKEN`). בלי טוקן ntfy חוסמת את הסקריפט כי שרתי גוגל משותפים להרבה משתמשים.
4. בהגדרות לוחצים **"בדיקת מערכת"**: כל השורות צריכות להיות ✓.

**אילו התראות יש** (כל אחת עם מתג פעיל/כבוי בהגדרות ← התראות):

| התראה | מתי |
|---|---|
| הנקה הסתיימה (שעת סיום, שעת הנקה הבאה, צד הבא) | מיד אחרי הנקה ארוכה, או אחרי זמן המתנה אחרי הנקה קצרה; ואז כל חצי שעה עד ההנקה הבאה |
| הנקה בעוד X דקות | כמה זמנים לבחירה: 5/10/15/20/30 |
| הגיע הזמן להנקה | כשמגיעה שעת ההנקה הבאה |
| תזכורות יומיות | כל ויטמין או תוסף, לתינוקת ולאמא, אם עוד לא נרשם שניתן |
| מים | כשהקצב מאחור ביחס ליעד היומי |
| תרופה לשיכוך כאבים | כשאפשר לקחת מנה נוספת (כבוי כברירת מחדל) |

התזכורות לתרופות הן תזכורת בלבד לפי המרווחים שהוגדרו, ולא ייעוץ רפואי.

**איך מוודאים שלא מפספסים התראות:**
- הסקריפט רושם בלשונית **"מצב התראות"** בגיליון מה הוא רואה ואם ntfy קיבלה כל הודעה (קוד 200). הודעה ש-ntfy דחתה נשלחת שוב בדקה הבאה.
- היומן בודק את השרת כל 10 דקות, וכשמשהו לא תקין מופיע **באנר אזהרה** במסך הבית (השרת לא רץ, הקוד בגיליון ישן, חסר טוקן, ntfy דוחה הודעות).
- הסקריפט מודד את זמן הריצה שלו. לחשבון גוגל רגיל יש כ-90 דקות ביום לטריגרים. מעל 60 דקות הוא מאט לבדיקה כל 5 דקות כדי לא לחרוג.
- מומלץ: ב-Apps Script ← Triggers ← Failure notification settings ← Notify me immediately.

**מגבלות:** אי אפשר להציג שעון שסופר לאחור במסך הנעול (רק אפליקציה אמיתית יכולה). התראה חדשה יוצאת רק אחרי שהטלפון סנכרן את הדיווח לגיליון. הסנכרון קורה כשהיומן פתוח.

## בדיקות

```
npm i playwright   # פעם אחת
node tests/gs.test.js    # חוקי ההתראות בסקריפט (מדמה את שירותי גוגל)
node tests/app.test.js   # היומן בדפדפן
```

הבדיקות רצות גם אוטומטית ב-GitHub (לשונית Actions) אחרי כל עדכון.
